# EchoPath 60 second demonstration

Before presenting, run the local app with no Supabase frontend variables and use a clean browser profile. State plainly: **This demo uses fictional records, deterministic extraction/synthesis, simulated approval and simulated email dispatch. No real AI request, shared-server save or email delivery is claimed.**

| Time          | Action                                                                                                                        | Suggested narration                                                                                                                                                       |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–7 seconds   | Home → Share experience                                                                                                       | Job descriptions miss the practical details. EchoPath captures the lessons each cohort can pass on.                                                                       |
| 7–20 seconds  | Fill fictional demo example → Continue through the four steps → choose publication consent and confirm public review → Submit | A short guided debrief keeps the original private. Contributors review exactly what others can see and choose whether to publish.                                         |
| 20–28 seconds | Show saved management link → Simulate approval & view insights                                                                | The anonymous public version is separate. This template organizes actual supplied tools and lessons. The management link supports editing and withdrawal.                 |
| 28–40 seconds | Library → search SQL → Synthesize matching experiences                                                                        | Skills-first discovery connects matching experiences. Counts come from these records, and each excerpt links to its source. The local synthesis is deterministic, not AI. |
| 40–49 seconds | Open a source → Build my preparation roadmap → Build my roadmap                                                               | Students can turn the evidence into practical weekly preparation, then save progress.                                                                                     |
| 49–60 seconds | Reminders → use a prepared enrollment/private reminder view → advance demo clock → Simulate dispatch                          | Opt-in end-date reminders close the capture loop. This is only a simulated dispatch; real email needs an authorized sender and scheduler.                                 |

For the one-minute presentation, prepare the reminder enrollment beforehand using a clearly fictional contact address; keep its private fragment link in a separate local browser tab. The reminder view demonstrates eligibility, message preview, no-email simulation, retry and completion/opt-out suppression. Never display real contact information to judges.

After the timed flow, optionally demonstrate withdrawal: use the private management link, withdraw, refresh the library, and show that new synthesis/roadmap requests cannot use the record. Ask for contextual helpfulness feedback. Do not publicly show private links, tokens, raw originals or private feedback comments from real contributors.

For a later live demonstration, first verify your own Supabase project, approved public records, authorized OpenAI connection, email sender and scheduler. Variable provider latency makes a prepared, already-approved real record preferable to pretending that a template is live AI. The one-minute script is a rehearsal plan, not evidence that student intake takes five minutes or that the product has passed user testing.
